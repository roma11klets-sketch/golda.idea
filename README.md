# Остров слов — 3D игра на выживание

Игроки появляются на острове. Случайно выбирают одного (шансы в %), он пишет два слова, и ИИ превращает их в событие, существо, предмет или здание. Побеждает последний выживший. Комнаты до 5 игроков.

## Запуск на компьютере
```
npm install
ANTHROPIC_API_KEY=ваш_ключ npm start
```
Откройте http://localhost:3000. Без ключа игра работает, но ИИ выключен (слова понимаются по списку ключевых слов).

## 1. Выложить на GitHub
1. На github.com нажмите **New repository**, назовите, например, `island-game`, создайте.
2. Нажмите **uploading an existing file** и перетащите ВСЁ содержимое этой папки (включая папку `public`, файлы `server.js`, `package.json`, `render.yaml`, `.gitignore`, `README.md`). Нажмите **Commit changes**.

## 2. Запустить на Render
1. Зайдите на render.com и войдите через GitHub.
2. **New +** -> **Blueprint** (или **Web Service**) -> выберите репозиторий `island-game`.
3. Если Web Service: Runtime `Node`, Build Command `npm install`, Start Command `npm start`.
4. В разделе **Environment** добавьте переменную `ANTHROPIC_API_KEY` со значением вашего ключа (ключ берётся в console.anthropic.com). По желанию `AI_MODEL`.
5. Нажмите **Deploy**. Через пару минут игра будет по адресу вида `https://island-game.onrender.com`.
6. Отправьте друзьям ссылку. Все вводят один и тот же код комнаты.

## Важно знать
- **Ключ никогда не кладите в код или на GitHub.** Только в переменные окружения Render.
- Запросы к ИИ платные по вашему ключу. Сервер ограничивает 15 запросов в минуту с одного адреса, но поставьте лимит расходов в консоли Anthropic.
- Бесплатный тариф Render засыпает без посетителей: первая загрузка может занять около минуты, пока он просыпается. Условия тарифов меняются, проверьте на сайте.
- Игра рассчитана на небольшие компании: каждый игрок считает урон своему персонажу сам, поэтому нечестные игроки теоретически могут жульничать.

## Как это устроено
- `server.js` — раздаёт игру, пересылает данные игроков комнаты по WebSocket и проксирует запросы к ИИ.
- `public/index.html` — сама игра, `public/shim.js` — подключает комнаты и ИИ к этому серверу.
